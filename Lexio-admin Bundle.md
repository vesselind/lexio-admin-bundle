Lexio-admin Bundle



This directory already contains some files that are extracted from another symfony web project. Those files puprose was to serve as a core of admin starter package, however integrated in existing project. This "package" provided ADMIN crud integradtion for ease creation of admin CRUD controllers and templates and other functionalities. Now I want this functionalities to be encapsulated in real package - in symfony bundle, in order to make this modular, easy to install and maintain on various symfony projects. 

Your task, therefore, is to turn those files into symfony bundle that is reusable and meets all the bundle and php package requirements. The bundle should be configurable as much as possible. It should be compatible with symfony 8.0 at least and php 8.4. You should use the AI skills in .claude folder of the current project while performing this task. 

You should also organize the files here in the proper symfony bundle way.

It is possible some files to be missing, while I copied them from the original symfony project. If you suspect that something essential could be missing you should warn me in order to look for the files in the old project and provide them to you.
