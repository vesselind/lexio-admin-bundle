## Ownership decisions recorded

- Generic admin layouts, CRUD templates, form themes, admin components, and maker templates belong
  to the bundle.
- Host SEO is now configured through `lexio_admin.ui.seo_template`.
- Host favicon, admin logo, title suffix, and generic UI routes are configured through
  `lexio_admin.ui`.
- Public-site layout and flash rendering are host-owned; public components are host-owned, while
  `ConfirmationModal` remains the bundle-owned exception.
- `submit-confirm` had no controller source. Generic menu forms now use native confirmation until
  a packaged Stimulus controller is deliberately introduced.
- The underscore form `collapsable_sidebar` is normalized to the Stimulus identifier
  `collapsable-sidebar`.
