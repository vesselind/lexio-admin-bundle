# v0.2.0

## Changes since v0.1.12

- Add reusable user administration and modal controllers with host-owned entities,
  invitation services and form types, plus bundle templates and English/Bulgarian translations.
- Render YouTube, Instagram and Facebook media through the new `ckeditor_content`
  filter, with sanitized rich text, responsive embeds and localized media-resize controls.
- Protect role updates with user-scoped CSRF tokens, reject ambiguous profile/password
  submissions, canonicalize Facebook plugin URLs and correctly parse YouTube timestamps.
- Support quoted and sentence-style YAML translation keys while preserving surrounding
  records, comments and line endings during updates.
- Add typed image-cache exceptions and a deprecated `TranslationController`
  compatibility alias for `TranslationPackageController`.
- Align the frontend package version with the bundle's minor release at `0.2.0`.

## Validation

- `make ci`: PHPStan clean; 370 PHP tests pass (1,843 assertions).
- `make assets-build` and `make assets-test`: pass; 30 frontend tests.
- Three existing PHPUnit notices remain. The installed development dependencies have
  four existing security advisories in PhpSpreadsheet and Symfony UX Icons; this release
  does not update those dependency constraints.

## Migration notes

- Upgrade the host dependency to `lexio/admin-bundle:^0.2` and refresh its Composer
  lockfile through the host project's Makefile. The new `symfony/html-sanitizer`
  dependency is installed with the bundle.
- Refresh the host's bundle asset package and run `make assets-install`,
  `make assets-build`, `make assets-test` and `make ci`. The frontend package version is `0.2.0`.
- To adopt the user controller, implement `UserEntityInterface`, alias
  `UserInvitationInterface` to the host invitation service, and supply the host forms,
  role choices and route/access rules as described in `docs/admin-user-controller.md`.
- Custom role forms must include `_token` generated with
  `csrf_token('admin.user.roles.' ~ user.id)` and enable `framework.csrf_protection`.
  Profile and password forms must have distinct names and be submitted separately;
  requests containing both form names now receive HTTP 400 before binding.
- The `ckeditor_content` filter removes scripts, event handlers, raw iframes and
  arbitrary inline styles. Numeric figure widths in `px`, `%`, `em` and `rem` remain.
  Convert manually authored iframes to supported semantic `oembed` media where needed.
  Custom `CKEditorExtension` definitions must inject the bundle's
  `CKEditorContentSanitizer` as `contentSanitizer`.
- `CKEditorType` services supply the editor locale and English/Bulgarian resize
  dictionaries automatically. Manually constructed types must receive the optional
  `translator` argument; standalone resize-plugin integrations must supply CKEditor
  `translations` configuration. Host overrides belong in the `ckeditor` YAML domain.
- To adopt the modal controller, extend `ModalController` and provide the searchable
  entity class and host route/access rules. Existing host implementations may remain.
